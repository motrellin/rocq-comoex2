# Personal Exercises for Rocq

This repository contains personal exercises which I use to introduce the interactive theorem prover [ROCQ](https://rocq-prover.org) to interested people.

## Repository Structure

In [`exercises/`](exercises/), you will find a collection of exercises.
My focus lies on the following topics:
- **Inductive Types, Recursion, Induction**
- **Relations and Setoid Equalities**
- **Coinductive Types**

Currently, the following files exist:
- [`exercises/Nat.v`](exercises/Nat.v): A soft introduction to inductive types, recursion, and induction. The exercises are designed in a fading out manner, meaning that more hints and explanations are given at the beginning, which are gradually removed in later exercises.
